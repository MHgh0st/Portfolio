# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Next.js (App Router) + Tailwind CSS v4 + TypeScript

## Users

Recruiters, Engineering Managers, Frontend Leads, and CTOs evaluating senior frontend architecture, UI/UX craft, web performance, and complex system visual engineering.

## Product Purpose

A senior frontend engineer portfolio for Mohammad Hossein Gholami (`MHgh0st`) designed to present advanced web architecture, complex interactive systems (GraphNext, ASCVD, Ticketing System), and exceptional visual craft.

## Positioning

Refuses generic developer templates, monochromatic dark-mode cards, and boring SaaS layout conventions. Establishes immediate authority through a high-contrast Swiss Editorial × Neo-Brutalism × Y2K technical aesthetic.

## Operating Context

Evaluated on desktop and mobile web browsers during high-velocity candidate filtering or engineering audits. Must load instantly, feel buttery smooth, and project high frontend engineering rigor within 3 seconds of landing.

## Capabilities and Constraints

- Responsive web interface (desktop & mobile)
- Asymmetric grid-driven layouts
- Real project integrations (GraphNext, ASCVD, Ticketing System)
- Interactive frontend performance & architectural breakdowns
- Clean TypeScript codebase

## Brand Commitments

- **Aesthetic Fusion:** Swiss Editorial structure × Neo-Brutalist physicality × Y2K digital/technical nostalgia.
- **Base Canvas:** Warm off-white / paper white ground (`#F4F3EF`), NOT dark mode and NOT pure white.
- **Typography:** Deep charcoal text (`#111111`), giant typographic identity lockups (`محمدحسین غلامی`), strict baseline grid.
- **Palette Accents:** Electric Cobalt Blue (`#0047FF`), Acidic Lime (`#D4FF00`), rare Saturated Red-Orange (`#FF3B00`).
- **Strict Anti-Patterns:** NO gradients, NO glassmorphism, NO dark SaaS default cards, NO centered generic heroes.

## Evidence on Hand

- Real projects from GitHub (`MHgh0st`):
  - **GraphNext:** Advanced graph & large data visualization engine built with Next.js 16, React 19, `@xyflow/react`, `elkjs`, D3 (d3-sankey), ApexCharts, Apache Arrow, msgpack, and HeroUI.
  - **ASCVD:** Medical cardiovascular 10-year risk calculator app built with Next.js 15, React 19, Supabase (PostgreSQL), Prisma ORM, NextAuth.js (SMS/bcrypt), React Gauge, and HeroUI.
  - **ticketing-system:** Enterprise ticketing platform built with Vue.js 3, Nuxt.js, Tailwind CSS, featuring 100% custom UI components (Chat Bubbles, Drawers, Modals) and SMS/Username authentication.

## Product Principles

- **Engineered Authority:** Senior frontend mastery displayed through sophisticated typographic & architectural layout.
- **Immediate Proof:** The first viewport is a living demonstration of UI/UX precision + frontend craft.
- **Intentional Color:** Colors act as flat structural graphic markers, never decorative background fills.
