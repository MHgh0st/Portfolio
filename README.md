# پورتفولیو مهندسی فرانت‌اند و سیستم‌های تعاملی // محمدحسین غلامی (MHGH0ST)

> **یک پورتفولیو پیشرفته با هویت بصری Swiss Editorial × Neobrutalism × Technical Blueprint**  
> تمرکز بر مهندسی سیستم‌های مقیاس‌پذیر فرانت‌اند، مصورسازی داده‌های حجیم، توسعه کراس‌پلتفرم نیتیو و ایجاد تعاملات پایدار در ۶۰ فریم بر ثانیه.

---

## ⚡ درباره پورتفولیو و فلسفه دیزاین (Design Philosophy)

این پورتفولیو بر پایه تلفیق سه سبک شاخص دیزاین مدرن خلق شده است:
1. **تایپوگرافی و ساختار شبکه سوئیسی (Swiss Editorial Grid):** ترازهای میلی‌متری، تایپوگرافی قدرتمند کلمه (FaNum)، خطوط هیرلاین CAD و لی‌اوت‌های نامتقارن.
2. **نئوبروتالیسم خالص (Raw Neobrutalism):** اشکال هندسی ۱۲ پَر، ستاره‌های رترو، کارت‌های بلیت پانچ‌شده، کادرهای ۲ پیکسلی مشکی و سایه‌های سخت سه‌بعدی (`shadow-[6px_6px_0px_#0047ff]`).
3. **بلوپرینت فنی و تعاملی (Interactive Blueprint HUD):** کراس‌هیر سفارشی، نوار پیشرفت اسکرول فنری، اسکرول‌بار اختصاصی و لایت‌باکس بزرگ‌نمایی بدون افت کیفیت.

---

## 🛠️ پشته فناوری‌ها (Tech Stack)

### Core Framework & Compiler
- **Next.js 16 (App Router)** & **React 19**
- **React Compiler (Babel Plugin)** جهت بهینه‌سازی خودکار رندرها و حذف مموایزیشن دستی
- **TypeScript 5** با تایپ‌سیفتی سخت‌گیرانه

### Styling & Design System
- **Tailwind CSS v4** با متغیرهای نوین تم و سیستم رنگی اختصاصی
- **HeroUI v3** بر پایه استاندارد دسترسی‌پذیری React Aria Components
- **تایپوگرافی فارسی کلمه (Kalameh FaNum)** در ۹ وزن مختلف

### Animation & Smooth Experience
- **Framer Motion 12 (Motion)** برای ترنزیشن‌های فیزیک فنری و پارالاکس ملایم
- **Lenis Smooth Scroll** ادغام‌شده با GSAP ScrollTrigger
- **Custom Native & HUD Scrollbar** با قابلیت درگ و نشانگر دقیق پیشرفت

## 🚀 راه‌اندازی و اجرای محلی (Local Development)

### پیش‌نیازها
- Node.js 20+ یا Bun / pnpm

```bash
# ۱. کلون کردن ریپازیتوری
git clone https://github.com/MHgh0st/Portfolio.git
cd Portfolio

# ۲. نصب پکیج‌ها
npm install
# یا با bun:
# bun install

# ۳. اجرای سرور توسعه
npm run dev
```

آدرس محلی: `http://localhost:3000`

### ساخت نسخه پروداکشن
```bash
npm run build
npm run start
```
